# 📊 Autonomous Data Analyst Agent

A Streamlit + Groq application that behaves like an autonomous junior data analyst.

## Architecture

User → Streamlit → Groq Planner → Deterministic Python/Pandas Tools → Visualizations → Verification → Groq Report

The LLM is responsible for:
- understanding the question
- creating a plan
- selecting analysis operations
- interpreting verified evidence
- communicating the result

Python is responsible for:
- data manipulation
- aggregation
- statistics
- outlier detection
- numerical calculations
- visualization

## 1. Create the environment

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

## 2. Install dependencies

```bash
pip install -r requirements.txt
```

## 3. Add the Groq key

Create:

```text
.streamlit/secrets.toml
```

Copy:

```toml
GROQ_API_KEY = "gsk_your_real_key"
GROQ_MODEL = "llama-3.3-70b-versatile"
```

Never commit this file.

## 4. Run

```bash
streamlit run app.py
```

## 5. Deployment

For Streamlit Community Cloud:
1. Push this project to GitHub.
2. Create a new Streamlit app.
3. Select `app.py`.
4. Add `GROQ_API_KEY` and `GROQ_MODEL` under the app's Secrets settings.
5. Deploy.

## Important security note

This version deliberately does NOT execute arbitrary Python code generated by the LLM. It maps the planner output to a fixed allow-list of analysis operations. That is safer for Streamlit deployment.

If arbitrary generated code is added later, execute it in a separate sandbox/container with strict CPU, memory, timeout, filesystem and network restrictions. Never expose secrets or the host filesystem to generated code.
